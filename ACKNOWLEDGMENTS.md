# Acknowledgments

The Large Anime Text Dataset aggregates public metadata that its original
providers make available to the anime and research communities. We are grateful
to:

- **AniList** — GraphQL API and community-maintained anime data
  (<https://anilist.co>, <https://graphql.anilist.co>; terms:
  <https://anilist.co/terms>).
- **Kitsu** — JSON:API for anime, episodes and characters
  (<https://kitsu.io>, <https://kitsu.io/api/edge>; terms:
  <https://kitsu.io/terms>).
- **Shikimori** — API for anime, manga and characters
  (<https://shikimori.io>; terms: <https://shikimori.io/terms>).
- **Wikidata** — the CC0 knowledge base behind the supplementary title
  cross-linking (<https://www.wikidata.org>;
  <https://www.wikidata.org/wiki/Wikidata:Licensing>).
- **Anime News Network Encyclopedia** — factual reference data
  (<https://www.animenewsnetwork.com/encyclopedia/>).

This release stands on the shoulders of those communities; the aggregation,
cross-linking, record summaries, non-synopsis QA, instruction and derived RAG
material is original to this project.

Upstream synopses, character biographies, episode summaries and tag definitions
are retained with attribution. They remain the property of the source that
published them, are excluded from this project's CC-BY-4.0 grant, and carry
`prose_source` and `prose_license` in the release. Attribution is not
permission.

See `NOTICE`, `LICENSE_AUDIT.md`, `exports/attribution.json` and
`exports/provenance.jsonl` for machine-readable, per-entity provenance and
license notes, and `docs/LICENSE_NOTES.md` for what each source's terms allow.

_Cited releases and counting_ — see `CITATION.cff` for the canonical citation.
