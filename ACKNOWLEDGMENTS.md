# Acknowledgments

The Large Anime Text Dataset aggregates public metadata that its original
providers generously make available to the anime and research communities.
We are grateful to:

- **AniList** — open GraphQL API and community-maintained anime data
  (<https://anilist.co>, <https://graphql.anilist.co>).
- **Kitsu** — open API for anime and episode metadata
  (<https://kitsu.io>, <https://kitsu.io/api/edge>).
- **Shikimori** — open API for anime, manga and characters
  (<https://shikimori.one>).
- **Wikidata** — the CC0 knowledge base behind the supplementary title
  cross-linking (<https://wikidata.org>).
- **Anime News Network Encyclopedia** — factual reference data
  (<https://www.animenewsnetwork.com/encyclopedia/>).

This release stands on the shoulders of those communities; the aggregation,
cross-linking, QA, instruction and RAG material is original to this project.
No narrative prose from these sources is redistributed: upstream synopses,
character biographies and episode summaries are excluded from every export,
and the summaries that remain are generated by this project from factual
fields.

See `NOTICE`, `LICENSE_AUDIT.md` and `exports/provenance.jsonl` for the
machine-readable, per-entity provenance and license notes, and
`docs/LICENSE_NOTES.md` for what each source's terms allow.

_Cited releases and counting_ — see `CITATION.cff` for the canonical citation.
