# Large Anime Text Dataset

A text-only anime corpus for LLM fine-tuning, instruction tuning, RAG, question
answering and entity linking: **35,766 works** and **2,436,445 structured text
rows**, with per-record provenance, confidence, leak-free splits and a
redistribution tier.

## Releases

| Release | Works | Rows | Access |
| --- | ---: | ---: | --- |
| [Full mixed-rights](https://huggingface.co/datasets/muqeet-1138/anime-text-dataset) | 35,766 | 2,436,445 | gated, manual approval |
| [Free 30% preview](https://huggingface.co/datasets/muqeet-1138/anime-text-dataset-preview) | 10,729 | 713,238 | gated, instant approval |
| [Public CC0 subset](https://huggingface.co/datasets/muqeet-1138/anime-text-dataset-open) | 969 | 8,654 | public |

The preview is free and does not require access to the full release. Gating is
access control, not a licence from AniList, Kitsu, Shikimori or Anime News
Network.
