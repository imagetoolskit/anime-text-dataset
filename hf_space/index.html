Load it in one line

JSONL is canonical; Parquet and CSV ship alongside it. Splits are assigned per work (90/5/5, seed 42), so no record of a work leaks across train, validation and test.

from datasets import load_dataset

qa = load_dataset(
    "muqeet-1138/anime-text-dataset-preview", "qa", split="train"
)
anime = load_dataset(
    "muqeet-1138/anime-text-dataset-preview", "anime", split="train"
)

print(qa[0]["question"], "->", qa[0]["answer"])
Licence note. Only 291 of the preview's 10,729 works are cc0_only. The rest carry upstream obligations; do not redistribute the files or derivatives.
