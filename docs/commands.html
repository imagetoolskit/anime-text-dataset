Terminal & CLI command reference

Every command works in Windows CMD, PowerShell, and Git Bash / WSL unless noted. Replace python with python3 where needed. The complete written guide is docs/COMMANDS.md.

SetupClone, install, verify

git clone <repo-url> && cd anime-text-dataset
python -m venv .venv
.venv\Scripts\activate        # Windows CMD/PowerShell
# source .venv/bin/activate  # Git Bash / WSL / macOS
pip install -r requirements.txt
python -m src.cli validate    # repository checks
python -m src.cli checksums   # SHA-256 manifest

ExploreRead the data from any shell

# count rows — PowerShell
(Get-Content exports\anime.jsonl | Measure-Object -Line).Lines
# count rows — Bash / WSL / macOS
wc -l exports/anime.jsonl
# first record — PowerShell
Get-Content exports\anime.jsonl -TotalCount 1
# SQLite — Python stdlib, no install
python -c "import sqlite3; con=sqlite3.connect('exports/anime_dataset.sqlite'); [print(r) for r in con.execute('select year,count(*) from anime group by year order by 2 desc limit 5')]"
# DuckDB over Parquet (pip install duckdb)
duckdb -c "select year, count(*) from read_parquet('exports/anime.parquet') group by year order by 1 desc limit 5;"
# one-line Python stream (no deps)
python -c "import json; A=[json.loads(l) for l in open('exports/anime.jsonl',encoding='utf-8')]; print(len(A), sum(1 for a in A if a['year']==2020))"

PipelineThe src.cli driver

One module regenerates every release artifact. Each phase is resumable.

CommandProduces
python -m src.cli discoverIDs per source
python -m src.cli dedup35,766 canonical works
python -m src.cli enrichdepth-tier detail (episodes, roles, relations)
python -m src.cli entitiescharacters · staff · studios · episodes
python -m src.cli normalizeduplicate works merged, enums canonicalized, values repaired, entities deduped
python -m src.cli relationships26,719 relationship edges
python -m src.cli descriptions35,766 descriptive texts
python -m src.cli qa291,816 QA pairs
python -m src.cli instructions211,569 instruction examples
python -m src.cli franchisefranchise clusters
python -m src.cli rag154,640 RAG chunks
python -m src.cli split90/5/5 splits per work
scripts/license_tiers.pyper-anime license tier, manifest and subset id lists
python -m src.cli exportJSONL + SQLite + Parquet + CSV, with split and license_tier joined
python -m src.cli validate21 quality checks over the exported files
python -m src.cli checksumsSHA-256 for every export
python -m src.cli reportreports/final_report.md + summary.json

TroubleshootCommon issues

SymptomFix
database is lockedrun pipeline phases in sequence; no parallel writers
Unknown command: Xrun python -m src.cli to list valid commands
UnicodeEncodeError in Windows$env:PYTHONIOENCODING='utf-8' (PowerShell) or chcp 65001 (cmd)
Checksum mismatchre-download the release asset or python -m src.cli export
Memory spike on large JSONLstream line-by-line (see explore examples above)
