What's insideA structured, text-only corpus

Each anime work expands into many related records, so you can train everything from a chat assistant to a retrieval system from one consistent schema.

Identity

Titles & metadata

Canonical, English and Japanese titles plus 135,425 alternative titles; type, status, episode counts, air dates, season, year, scores, popularity, favourites, source material and age rating per work.

Narrative

Episodes & relations

276k episodes with titles and dates; 39,226 relationship edges (sequel, prequel, side story, adaptation) and 23,980 franchise clusters built from them.

People

Cast & crew

283,477 characters and 535,642 staff rows with roles — the raw material for character Q&A, dialogue-style data, and voice-actor modelling.

Text

Record summaries

63,396 description rows: project-written summaries assembled from each work's own structured fields, plus the upstream synopsis where one was published, carrying its source and licence status.

Training

QA & instructions

317,907 grounded QA pairs and 235,395 instruction examples — chat-style, ready to shard for SFT, LoRA/QLoRA and DPO.

Retrieval

RAG chunks

206,906 semantic chunks, each with source references, sized for embedding models and retrieval-augmented generation.

Knowledge graph

Entity links

77,681 records mapping every internal anime ID to external source IDs with method and confidence — for entity linking and KG construction.

Provenance

Sources & confidence

Every record carries its source, remote ID, link method, confidence, and quality tier A/B/C so you can filter by how reliable a record is.

License note: original code, structure and generated text are CC-BY-4.0. Retained upstream synopses, biographies and tag definitions are excluded from that grant: every prose row carries prose_source and prose_license, and exports/attribution.json names each owner and terms URL. Every anime row also carries one license_tier — cc0_only, permission_required or unresolved — set by its strictest contributing metadata or prose source. exports/license_manifest.json states what each tier permits; exports/license_commercial_clear.csv lists the rows with no permission request outstanding. Tiers describe this dataset's provenance obligation, not the copyright status of the underlying works.

SplitsLeak-free train / validation / test

90 / 5 / 5 by work, not by row

Split assignment happens per anime work. Every character, QA pair, chunk, and relationship of a work lands in the same bucket — no information leakage between training and test. Seed 42, auditable via the split field on every exported record.

Quick startRun it from any terminal

These commands work in Windows CMD, PowerShell, Git Bash and WSL. Replace python with python3 where needed.

Clone & install

git clone <repo-url> && cd anime-text-dataset
python -m venv .venv
.venv\Scripts\activate      # Windows
# source .venv/bin/activate  # Bash/WSL/macOS
pip install -r requirements.txt

Verify the data

python -m src.cli validate
python -m src.cli checksums

Inspect without training

# count rows  -  PowerShell
(Get-Content exports\anime.jsonl | Measure-Object -Line).Lines
# count rows  -  Bash/WSL
wc -l exports/anime.jsonl
# SQL anime query, no install needed
python -c "import sqlite3; con=sqlite3.connect('exports/anime_dataset.sqlite'); [print(r) for r in con.execute('select year,count(*) from anime group by year order by 2 desc limit 5')]"

Open the full command reference for every flag, environment variable, and the exact commands to explore JSONL, SQLite, and Parquet.

Reproducible buildEvery part of the release is one command

A single deterministic driver (python -m src.cli) regenerates every table from source payloads. Each phase is resumable and checkpointed.

P0python -m src.cli discoverids per source
P1python -m src.cli dedup35,766 canonical works
P2python -m src.cli enrichdepth-tier detail
P3python -m src.cli entities → normalizecharacters · staff · studios · episodes, deduped
P4python -m src.cli relationships39,226 edges
P5python -m src.cli descriptions63,396 texts
P6python -m src.cli qa317,907 pairs
P7python -m src.cli instructions235,395 examples
P8python -m src.cli franchisefranchise clusters
P9python -m src.cli rag206,906 chunks
P10python -m src.cli split90/5/5 per work
P11scripts/license_tiers.py → python -m src.cli exporttier + split joined into every row
QApython -m src.cli validate · checksums · report21 checks + report
